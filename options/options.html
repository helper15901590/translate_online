网页视频转文字

捕获标签页正在播放的音频，交给阿里云百炼（DashScope）识别成文字，可导出 Markdown。

接口凭据

在阿里云百炼控制台的「API-KEY 管理」里创建。 Key 只保存在这台电脑的浏览器本地存储里，不会上传到任何第三方。

Key 与地域必须匹配：北京站和国际站的 Key 互不通用。

如果控制台给你的是带 WorkspaceId 的专属域名，把域名部分填在这里（不要带路径）。

两条通道接的是同一个模型，任选其一即可。识别报参数错误时可以换另一条试试。

同步接口单次限 10MB / 5 分钟以内，插件会自动把音频切片后逐段识别。

识别参数

指定已知语言能明显提升准确率；不确定就留「自动检测」。

音频每隔这么久切一段送出去识别。切得短，出结果更快、失败重试代价更小；切得长，跨句连贯性略好。 建议 30–90 秒。

采样率越高音频体积越大，但对识别准确率几乎没有帮助。

填入人名、术语、专有名词，能显著降低这些词的错误率。留空即可。

逐段翻译与生词

和语音识别是两个独立配置。推荐 qwen-plus（质量与价格平衡）； 追求速度用 qwen-flash。 该模型必须支持 JSON 输出，否则会报参数错误。

如果和上面的「音频语言」是同一种，插件会自动跳过翻译，不会白花请求。

低于这个难度的词不会被挑出来，避免满屏都是 the、make 这类基础词。

按重要性排序，超出部分会被丢弃。

录制与导出

可用占位符：{title} 页面标题、{date} 日期、{time} 时间、 {site} 站点域名、{model} 模型名。
